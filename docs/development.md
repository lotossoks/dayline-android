# Устройство Dayline

## Слои

- `core/Model.java` — группы, задачи, сеансы и снимок данных.
- `core/TimeMath.java` — границы календарных периодов, обрезание по периоду, сумма и объединение интервалов, пробелы и вырезание участка.
- `core/ExcelReport.java` — создание OOXML-книги непосредственно на устройстве. Строки записываются как текст, включая названия, начинающиеся с `=`. Экспорт одной группы не сериализует чужие имена и описания.
- `core/AnalysisMath.java` — выбор задач, средние за календарные дни и дни недели, почасовая занятость с объединением пересечений, планирование заполнения пропусков.
- `AnalysisScreen.java`, `AverageChartView.java`, `GapFiller.java` — анализ, график среднего дня и пакетное заполнение.
- `Store.java` — SQLite, транзакции, проверки пересечений одной задачи, отмена правки и проверяемый импорт JSON.
- `MainActivity.java`, `Ui.java`, `Editors.java`, `TimelineView.java` — экраны, редакторы, лента и системный выбор файлов.
- `TimerService.java`, `BootReceiver.java` — уведомление с управлением по группам и восстановление после перезагрузки.

## Инварианты

1. Работающий сеанс имеет `ended = NULL`. Частичный уникальный индекс допускает не более одного такого сеанса на задачу.
2. Разные задачи могут пересекаться. Повторный ручной интервал одной задачи отклоняется, включая пересечение с работающим сеансом.
3. Закрытый сеанс имеет начало раньше окончания. В будущую дату записывать нельзя.
4. Вырезание, перенос, восстановление и остановка группы выполняются транзакционно. Конфликт переноса оставляет исходные данные неизменными.
5. «Не учтено» — дополнение объединения всех интервалов до текущего момента, не до будущего конца дня/недели.
6. Границы дня и недели определяются `java.time` в текущем часовом поясе. День не предполагается равным ровно 24 часам.
7. Excel использует один момент снимка для всех листов. Время вне выбранной группы не выдаётся за отсутствие активности.
8. Фоновые таймеры не требуют ежесекундной работы или блокировки сна устройства. База с временными отметками остаётся источником данных.

Системное ручное изменение часов может влиять на длительность незавершённых сеансов; их можно исправить через историю. Перевод часового пояса меняет календарное представление уже сохранённых абсолютных отметок.

## Проверки

`scripts/test-core.sh` запускает независимые от Android проверки интервалов: наложения, сутки с переходом на летнее/зимнее время, границы недели, заполненность, вырезание и 500 воспроизводимых случайных наборов. Также создаёт синтетические Excel-книги и проверяет отсутствие личных строк в экспорте выбранной группы.

`DaylineInstrumentation` работает с отдельной тестовой SQLite-базой и проверяет параллельные таймеры, остановку группы, повторное открытие базы, закрытие задачи, правки, конфликты и откат транзакций, отмену, резервное копирование и восстановление. Затем запускает основной экран. Основная база приложения в обычном тестовом режиме не очищается.

Параметр `-e timeline true` проверяет фактическое отображение цветных интервалов в начале и конце длинной недельной ленты. Это регрессия для ограничения программного слоя Android на большой диаграмме. Параметр `-e ui true` проверяет основные действия через интерфейс и требует пустой установки на тестовом устройстве.

Параметр инструментального теста `-e seed true` добавляет демонстрационные данные **только при явном вызове тестового APK** в пустую базу. Тестовый APK не включается в пользовательский выпуск.

GitHub Actions запускает проверки ядра, Android Lint и сборку debug/test APK. Подписанная пользовательская сборка создаётся отдельно с приватным ключом.

## Формат резервной копии

JSON: `format=dayline`, `version=1`, `exportedAt`, массивы `groups`, `tasks`, `sessions`. При импорте проверяются формат, размеры, уникальность идентификаторов, ссылки, временные границы и отсутствие пересечений одной задачи. Файл читается с ограничением 25 МБ. Неизвестные версии отклоняются без изменения базы.

## Границы первой версии

- Один телефон, локальные данные; облачная синхронизация отсутствует.
- Отчёты — день и календарная неделя; недельное сравнение и произвольные диапазоны не добавлены.
- Диаграмма в приложении допускает увеличение; точные времена доступны через нажатие и список записей. Excel-лента имеет часовую сетку с длительностью внутри каждого часа; точные рабочие границы — на листе «Интервалы».
- Уведомления на реальном устройстве зависят от пользовательских разрешений и ограничений производителя.

## Изменения 1.1.0

Схема SQLite и версия базы остаются равными 1; миграция и очистка данных не требуются. `applicationId=app.dayline`, прежний приватный ключ подписи, `versionCode=2`.

Выбор задач хранится в локальных настройках по ID. Непустой и пустой активный выбор различаются: пустой даёт ноль, а сброшенный — все задачи текущей группы. Явный выбор действует через границы групп. Экспорт получает отдельный снимок выбранных ID, который сохраняется при пересоздании Activity во время системного выбора файла.

Для средних знаменатель не меняется при исключении задач: учитываются все завершённые календарные дни от начала истории, включая пустые. Занятость каждой группы в часовой диаграмме сначала объединяется внутри каждого дня. Для повторяющегося часа при смене часового пояса учитывается реальная экспозиция; диаграмма не превышает 100%. Времена записей остаются абсолютными.

`fillGaps` вычисляет интервалы заново из актуальной базы внутри транзакции, исключает существующие записи целевой задачи и сохраняет всю операцию как одну отменяемую правку. Повторное применение не дублирует время. Граница «сейчас» фиксируется при открытии предпросмотра.

Дополнительный сценарий на **отдельной пустой тестовой установке**:

```bash
adb shell am instrument -w -e analysis true app.dayline.test/app.dayline.DaylineInstrumentation
```

Он создаёт синтетическую историю за 14 дней и проверяет реальный интерфейс: долгое нажатие, выбор двух задач без офиса, обе суммы, средние, сброс выбора, выбор дня недели и заполнение минутного пропуска с отменой. `tests/AnalysisTest.java` отдельно проверяет математику средних, пустые дни, переход через полночь, DST и покрытие пропусков.
