# Требования Dayline

Статус: интервью перед реализацией. Раздел «Подтверждено» отражает ответы пользователя; предложения и вопросы не считаются согласованными.

## Подтверждено

### Назначение и поставка

- Полноценное приложение для Android с установочным APK.
- Личное использование на одном телефоне; ориентир совместимости — Android 15.
- Основной горизонт анализа — неделя, с подробным просмотром каждого дня.
- Цель анализа — увидеть, чем заполнено время, и подготовить отчёт о работе по задачам.
- Самостоятельный проект и новый публичный репозиторий GitHub.

### Трекинг

- При открытии приложения выбран режим трекинга.
- Второй режим — анализ.
- Основные группы представлены вкладками, доступными свайпом влево и вправо.
- Начальные группы: «Работа», «Жизнь», «Сон». Можно создавать новые.
- Внутри группы — задачи с коротким названием и необязательным раскрываемым описанием.
- Задачи и группы можно создавать из обоих режимов.
- У задачи есть запуск и остановка таймера.
- Разрешены несколько одновременно работающих таймеров, в том числе в одной группе.
- Активные задачи поднимаются в начало своей группы.
- Нужен поиск задач по названию.
- У каждой задачи и группы видны накопленные значения за сутки и неделю.
- Произвольный диапазон дат не нужен.
- В заголовке группы нужна кнопка остановки без кнопки запуска; область её действия ещё уточняется.

### Жизненный цикл задач

- Задачу можно запускать многократно в течение длительного времени.
- Конкретную выполненную задачу можно закрыть и убрать из активного списка.
- История закрытых задач должна оставаться доступна для анализа и исправлений.
- Постоянные занятия, например сон и учёба, могут оставаться открытыми без срока завершения.
- Отдельные вложенные подгруппы пока не подтверждены; текущий пример структуры — группа → задача.

### История и исправления

- Хранятся отдельные интервалы с датой и временем начала и окончания, а не только суммарная длительность.
- Можно вручную изменить начало и окончание записи.
- Можно вырезать участок внутри записи.
- Вырезанный участок можно перенести в другую существующую задачу.
- Можно вручную добавить пропущенный интервал.
- Исправления должны выполняться быстро, с понятными действиями и минимальным количеством шагов.

### Анализ

- Временная лента по типу диаграммы Ганта для суток и недели.
- Представление должно обновляться с учётом текущих работающих таймеров.
- Параллельные активности допустимы; сумма длительностей задач может превышать 24 часа за сутки.
- Промежутки без трекинга должны быть видны.
- Нужны наполнение недели и распределение времени по задачам и группам.
- Сравнение разных недель не требуется.
- Для рабочего отчёта требуется понятный учёт недельных часов; способ представления пересечений ещё уточняется.

### Данные и экспорт

- Основные данные хранятся на телефоне.
- Экспорт в настоящий файл Excel `.xlsx`.
- В файле должны быть подробные данные и готовая статистика, не требующая самостоятельного построения сводок.
- Интеграция с Google Sheets не входит в текущий согласованный объём.

## Открытые решения

1. Кнопка остановки в заголовке завершает таймеры текущей группы или все таймеры приложения?
2. Какое значение считать основным в рабочем отчёте при пересечениях: сумму часов задач или фактическую занятость без двойного счёта?
3. Когда начинается отчётная неделя и в какой момент проходят границы суток?

## Предложения для следующего обсуждения

- Показывать обе величины: сумму часов задач и время занятости без повторного учёта пересечений.
- Начало недели — понедельник; граница суток — 00:00 по времени телефона.
- Интервал, пересекающий полночь или начало недели, распределять по соответствующим суткам и неделям, сохраняя исходную запись.
- Промежутки «Не учтено» определять по отсутствию любых активностей; дополнительно показывать пустоты на временных дорожках отдельных задач.
- Предварительный состав Excel: «Обзор недели», «По дням», «По группам», «По задачам», «Интервалы».
- Для завершённых задач предусмотреть возврат в активный список при ошибочном закрытии.

Эти предложения ещё не являются подтверждёнными требованиями.
